# DASHBOARD/webpage

Next.js visualization dashboard for the ANI-KUTA project.

> **Status: planned (Phase 5).** Not yet scaffolded.

## Purpose
Visual representation of the project:
- Module map (graph of modules + dependencies)
- Progress (read from `AGENT-CONTEXT/memory/progress.md`)
- Decisions log (read from `AGENT-CONTEXT/memory/decisions.md`)
- Blockers / open questions
- Logic / data flow diagram
