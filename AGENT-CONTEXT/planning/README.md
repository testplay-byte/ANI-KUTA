# Planning — Approach & Phases

> How we plan the project, phase by phase.

## Approach
- **Plan first, build second.** No random decisions.
- Each phase has its own file: `planning/phase-<n>-<name>.md`.
- Every plan is stress-tested by a sub-agent (see `skills/subagent-review.md`).
- The user confirms key decisions before execution.

## Per-Phase File Template
Each `planning/phase-<n>-<name>.md` contains:
- Goal
- Steps
- Assumptions
- Risks
- Sub-agent review notes
- User confirmations needed
