# Lessons Learned — Self-Learning Log

> One-line lessons from mistakes, corrections, and insights.
> Read at task start (grep for tags matching your task type). Append when you learn something.

## How to Use

- **Trigger**: log an entry when (a) the user corrects you, OR (b) you catch your own mistake before/after continuing, OR (c) you have an insight worth remembering.
- **Format**: `- [TAG] lesson (source: <task-id or "self">, <YYYY-MM-DD>)`
- **Tags**: `MISTAKE` (you did wrong), `CORRECTION` (user fixed you), `INSIGHT` (realized), `PATTERN` (recurring).
- **Dedup**: grep existing entries for the keyword before adding. Don't log the same lesson twice.
- **Stale**: mark `~~strikethrough~~` with `→ superseded by <ref>` when a newer entry contradicts.
- **Promote**: if a lesson is a recurring `PATTERN`, also add a one-line rule to `CORE_RULES.md`.

- [INSIGHT] ChildFirstPathClassLoader is REQUIRED for Aniyomi extension loading — the extension's bundled deps (Jsoup, OkHttp) must win over the app's classpath, with binary-compat only at the source-api boundary. A plain PathClassLoader causes NoClassDefFoundError when the extension's dep version differs from the app's. (source: loader fix, 2026-08-03)
- [MISTAKE] `kotlinx.coroutines.sync.withLock` is a suspend function — it can only be called inside a coroutine body, NOT inside a `flow {}` builder's lambda (which is a non-suspend context). Either use `flow { ... }.flowOn(Dispatchers.IO)` with a `mutex.withLock` inside a `launch`, or restructure so the lock is inside a suspend scope. (source: CI failure, 2026-08-03)
- [MISTAKE] `intent.resolveActivity()` returns null on Android 11+ (API 30+) for implicit intents like `ACTION_DELETE` due to package-visibility filtering — EVEN THOUGH `startActivity()` would succeed. Do NOT guard with `resolveActivity()`; just `startActivity()` in try/catch. Add a `<queries>` block in the manifest for defensive visibility. (source: user feedback, 2026-08-03, uninstall dialog not showing)
- [MISTAKE] `untrustExtension` must actually REVOKE the trust by fingerprint (`trustService.revoke(signatureHash)`) — just calling `loadAll()` re-trusts the same fingerprint because it's still in the trusted set. Store `signatureHash` on the `Installed` model so untrust has the fingerprint to revoke. (source: user feedback, 2026-08-03, "some extensions do not get untrusted")
- [INSIGHT] Extension icons: use `appInfo.loadIcon(packageManager)` to get the launcher icon Drawable, then render with Coil's `AsyncImage(model = drawable)`. Coil accepts Drawable as a model — no manual Drawable→ImageBitmap conversion needed. (source: icon fix, 2026-08-03)

- [MISTAKE] Aniyomi extensions use Injekt (a service locator) to resolve NetworkHelper, Application, Context, and Json. `AnimeHttpSource.network` is `by injectLazy()` — the first HTTP request triggers `Injekt.get<NetworkHelper>()`. Always register Injekt singletons in App.onCreate() BEFORE any extension loads. (source: user feedback, 2026-08-03, "No registered instance on Factory for type class eu.kanade.tachiyomi.network.NetworkHelper")

- [MISTAKE] RxJava `Observable.awaitSingle()` does NOT automatically move network IO to a background thread. The Observable's `subscribeOn`/`observeOn` determine the thread, and Aniyomi extensions often don't set these. ALWAYS wrap `fetchVideoList().awaitSingle()` / `fetchEpisodeList().awaitSingle()` / `fetchSearchAnime().awaitSingle()` in `withContext(Dispatchers.IO)` to avoid `NetworkOnMainThreadException`. (source: user feedback, 2026-08-03, "Resolution failed: android.os.NetworkOnMainThreadException")
